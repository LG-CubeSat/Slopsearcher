# Slopsearcher
New experimental subsidiary project of LG-CubeSat.

At LG-CubeSat, we constantly have to research things that a human simply doesn't have to. They are such menial tasks that AI could do just as well, however, the AI needs all the knowledge that we as members of the project have and a long running server to work on, while we as students are in classes. The solution to this problem is slopsearcher. It is given all the knowledge that we as members have, and can execute long running research tasks through a discord bot.

Cheers to making life easier 🥂.
